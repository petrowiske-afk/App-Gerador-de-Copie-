# Gerador de Copies para sites
App 100% estático (sem servidor, sem API paga). Gera o prompt de copy e o prompt final para o Claude Code.

## Publicar grátis
1. Crie um repositório no GitHub e envie `index.html` e este README.
2. Vercel (plano Hobby, grátis): Add New → Project → importe o repositório → Deploy.
   (Alternativa: GitHub Pages em Settings → Pages → branch main.)
